## Tech Stack

- HTML / CSS / JavaScript (no build step)
- Three.js (loaded from a CDN) for the scroll-driven 3D network scene
- Archivo and Instrument Serif from Google Fonts
- Hosted on AWS Amplify
- CI/CD via GitHub

## Files

- `index.html` - page content, one `<section class="chapter">` per story chapter
- `style.css` - layout, type, scroll reveal, and the mobile layout (below 768px)
- `main.js` - tracks the active chapter, updates the dot rail and caption, copy-email button
- `scene.js` - the Three.js scene; each chapter has its own node layout, and the scene morphs between them as you scroll

The page still works without JavaScript or WebGL: all text stays visible and the background falls back to a gradient. Visitors with "reduce motion" turned on get plain fades and a still scene.
